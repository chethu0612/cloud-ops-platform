# cloud-ops-platform

A learning project: a small Cloud Operations API that I am building to practise Linux, Python, FastAPI, Docker, CI/CD and AWS.

## Status
Just started. Nothing is built yet.

## Why I am building this
I work in infrastructure support and want more hands-on practice building and running systems myself, instead of mostly following existing runbooks. This project is how I am practising Linux, Python, FastAPI, Docker and AWS by building, breaking and fixing a small API.

## Planned features
- Health, disk, memory and service-status endpoints
- Incident create/read/update/delete with SQLite
- Tests with pytest
- Docker, GitHub Actions and Terraform

## Rules I follow
- I write the code myself and test everything.
- No secrets are committed.
